Promise API

6 Primary Methods()

There are 6 static methods of Promise class :

  1. Promise.all([p1, p2, ...]) -> Waits for all the promises to resolve and returns an array of their results. If any one fails, it becomes the error & all other results are ignored.
  2. Promise.allSettled([p1, p2, ...]) -> Waits for all the promises to settle/resolve and returns their results as an array with status & value.
  3. Promise.race([p1, p2, ...]) -> Waits for the first promise to settle/resolve and its result/error the output.
  4. Promise.any([p1, p2, ...]) -> Waits for the first promise to fulfill (& not reject), & its result becomes the output. Throws AggregateError if all the promises reject.
  5. Promise.resolve(value) -> Makes a resolved promise with the given value.
  6. Promise.reject(error) -> Makes a rejected promise with the given error.
