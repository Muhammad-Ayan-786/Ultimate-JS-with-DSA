Promises

Promises are a way to handle asynchronous operations in JavaScript. They provide a way to handle the success and failure of an asynchronous operation. Promises are often used with async/await syntax.

Promises Returned Properties

The Promise Object returned by the new Promise constructor has these following properties.

NOTE :
  • Promise state & result are internal
  • You cannot access them directly like promise.state
  • They are shown in DevTools for debugging only
  1. state : Initially pending, then changes to either "fulfilled" when resolve is called or "rejected" when reject is called.
  2. result : Initially undefined, then changes to either the value passed to resolve resolve(value) or the value passed to reject reject(value).
