Cookies

A cookie is a small text file that is downloaded to your computer when you visit a website. It contains information that is necessary for the website to function properly.

Cookie are set by a Web server using the Set-Cookie HTTP-header. Next time when the request is sent to the same domain, the browser sent the cookie using the Cookie HTTP-header. The way the server knows who sent the request.

Cookie are small strings of data stored directly in the user's browser.
In JavaScript, document.cookie provide access to cookies.

Property : alert(document.cookie)
NOTE : Contains key = value pairs
Delimited by a semicolon ';'

encodeURIComponent

This function helps to keep the valid formation. It is used like this :

document.cookie = `${encodeURIComponent(key)} = ${encodeURIComponent(value)}`;

This way, especial characters are encoded.

decodeURIComponent

This function helps to decode the encoded string.

console.log(decodeURIComponent("4%3Dfgd5=69v%3B60%2F3"));

This way, especial characters are decoded.

Cookies have several options which can be provided after key=value to a set call like this :

document.cookie = "user = Ayan; path = /a; expires = Thu, 18 Dec 2022 12:00:00 UTC";

path options makes the cookie visible at /a, /a/b etc. expires sets the cookie expiration date.

1. The name=value pair, after encodeURIComponent, should not exceed 4kb.

2. Total number of cookies per domain is limited to around 20+ (Exact number is browser dependent)
