Scope

Scope refers to the visibility and accessibility of variables, functions, and other elements in a program. It determines what parts of a program can access and modify the variables.

There are three types of scope in JavaScript:

  • Global Scope
  • Funtion Scope
  • Block Scope

Global Scope : The variables declared outside of any function or block are called global scope. They are accessible from anywhere in the program.

Function Scope : The variables declared inside a function are called function scope. They are only accessible within that function.

Block Scope : The variables declared inside a block are called block scope. They are only accessible within that block.

let & const provide block level scope which means that the variables declared inside a { } cannot be accessed from outside the block.

{ let a = 8; } // a is not available here console.log(a); // ReferenceError: a is not defined

Variables declared within a JavaScript function, become local to the function.

A variable declared outside of a function, becomes global.
