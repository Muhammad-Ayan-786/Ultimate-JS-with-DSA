Closures in JavaScript

A closure is created when a function remembers variables from its outer (lexical) scope, even after the outer function has finished execution.

What is a Closure?

In simple words, a closure allows a function to access variables defined outside of it.

A closure consists of:

  • A function
  • Its lexical environment

Simple Closure Example

In the example below, the inner function remembers the variable from the outer function. 

                
                    function createCounter() {
                        let count = 0;

                        return function () {
                            count++;
                            console.log(count);
                        };
                    }

                    const counter = createCounter();
                    counter(); // 1
                    counter(); // 2
                    counter(); // 3

Even after createCounter() finishes, the returned function still has access to the count variable.

Why Closures Are Useful

  • They allow data privacy
  • They help manage state
  • They avoid global variables

Common Use Cases

  • Event handlers
  • Callbacks
  • Timers (setTimeout)
  • Function factories

Interview Definition

A closure is a function bundled together with its lexical environment, allowing it to access variables from its parent scope even after execution.
