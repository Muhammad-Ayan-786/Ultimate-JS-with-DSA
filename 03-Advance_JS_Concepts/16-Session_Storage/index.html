Session Storage

Used less often than local storage. Properties & methods are same as local storage. BUT :

1. The Session Storage exists only within the context browser tab. Another tab with same page will have a different storage.

2. The data survives page refreash, but not closing/opening the tab.

Storage Event

When the data gets updated in localSrorage or sessionStorage, storage event triggers with these properties :

  1. key - The key of the changed item
  2. oldValue - The previous value of the item
  3. newValue - The new value of the item
  4. url - The URL of the page where the change occurred
  5. storageArea - The storage area where the change occurred (localStorage/sessionStorage)

We can listen the onstorage event of window which is triggered when updates are made to the same storage from other documents.
