Hoisting

Hoisting refers to the process whereby the interpreter appears to move the declaration to the top of the code before execution.

Variable can thus be referenced before they are declared in JavaScript.

Important Note : JavaScript only hoists declarations, not initializations. The variable will be undefined until the line where it is declared is executed.

Hoisting in Action

/* Example */ hello("Ayan"); // Works ! function hello(name) { ... }

Actual Hoisting Under the Hood

// Code console.log(x); var x = 10; console.log(x); // JavaScript Engine var x; console.log(x); // undefined x = 10; console.log(x); // 10 // NOTE : DECLARATION HOISTED TO THE TOP BUT INITIALIZATION IS NOT

Hoisting will const/let & var

With let & var, hoisting is different.

/* Example */ console.log(num); // Error if let or const With var undefined will print let num = 6;

Function expression and class expression are not hoisted
