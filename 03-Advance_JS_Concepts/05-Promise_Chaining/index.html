Promise Chaining

Promise chaining is a technique where you can use the result of one promise to create a new promise. This is useful when you want to perform multiple asynchronous operations in sequence.

Chaining Promise Example Code

const promise = new Promise((resolve, reject) => { // Initial promise setTimeout(() => resolve(1), 1000); }); promise.then((result) => { alert(result); return new Promise((resolve, reject) => { setTimeout(() => resolve(result + 1), 1000); }); }).then ...

The flow of the above code is as follows :

  1. The Initial Promise is resolved after 1 second.
  2. The next .then() handler is then called, which returns a new Promise (resolved with 2,after 1 second).
  3. The next .then() gets the result of the previous one and this keeps on going.

Every call to .then() returns a new Promise, whose value is passed to the next .then() and so on.
