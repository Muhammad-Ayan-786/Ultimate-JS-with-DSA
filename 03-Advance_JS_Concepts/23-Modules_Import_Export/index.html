JavaScript Modules

Modules allow us to split our JavaScript code into multiple files, making it cleaner, reusable, and easier to maintain.

1️⃣ Why Modules?

  • Avoid huge single JS files
  • Reuse code across projects
  • Prevent global variable conflicts
  • Write scalable applications

2️⃣ CommonJS Modules (Node.js)

CommonJS is mainly used in Node.js. It uses module.exports and require().

Export (CommonJS)
const hello = () => {
    console.log("Hello");
};

const greet = (name) => {
    console.log(`Hello ${name}`);
};

module.exports = { hello, greet };
Import (CommonJS)
const { hello, greet } = require("./script.js");

hello();
greet("Ayan");
Golden Rules (CommonJS):
  • You can export ONE thing using module.exports
  • Multiple values must be wrapped in an object
  • Uses require() to import

3️⃣ ES Modules (Modern JavaScript)

ES Modules (ES6) are the modern standard. They work in browsers and Node.js.

Named Export
export const hello = (name) => {
    console.log(`Hello ${name}`);
};

export const bye = (name) => {
    console.log(`Bye ${name}`);
};
Named Import
import { hello, bye } from "./script.js";

hello("Ayan");
bye("Ayan");
Named Export Rules:
  • Can export MANY things
  • Import MUST use the SAME names
  • Must be inside { }

4️⃣ Default Export (Single)

Export (Default)
const sayHello = () => {
    console.log("Hello World");
};

export default sayHello;
Import (Default)
import anyNameYouWant from "./script.js";

anyNameYouWant();
Default Export Rules:
  • ONLY ONE default export per file
  • Import name can be ANYTHING
  • No { } needed

5️⃣ Default Export with Multiple Values

If you want to default-export MORE THAN ONE thing, you must wrap them inside an object.

Export
const hello = (name) => console.log(`Hello ${name}`);
const bye = (name) => console.log(`Bye ${name}`);

export default { hello, bye };
Import
import myFuncs from "./script.js";

myFuncs.hello("Ayan");
myFuncs.bye("Ayan");
Destructuring Default Object
import myFuncs from "./script.js";

const { hello, bye } = myFuncs;

hello("Ayan");
bye("Ayan");

6️⃣ ❌ Common Mistakes

❌ This will NOT work: 
import { hello } from "./script.js"; // when hello is default export
❌ This will NOT work: 
import hello from "./script.js"; // when hello is named export

7️⃣ Golden Rules (FINAL)

Named Export    → import { sameName }
Default Export  → import anyName
Default Object  → import obj → obj.prop

8️⃣ Browser Note

To use ES Modules in HTML, always write: 

<script type="module" src="script.js"></script>
Without type="module", ES imports will NOT work in browsers.
