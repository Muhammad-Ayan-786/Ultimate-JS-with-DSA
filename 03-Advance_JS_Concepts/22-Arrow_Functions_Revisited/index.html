Arrow Functions in JavaScript

Arrow functions provide a shorter syntax for writing functions. They also behave differently with this compared to regular functions.

Basic Syntax

Classical arrow function:


                const sayHello = () => {
                    console.log("Hello");
                };
                sayHello();

Single-line arrow function:


                const sayHello2 = () => console.log("Hello");
                sayHello2();

Parameters

Single parameter (no parentheses needed):


                const greet = name => console.log(`Hello ${name}`);
                greet("Ayan");

Multiple parameters (parentheses required):


                const greetFullName = (firstName, lastName) =>
                    console.log(`Hello ${firstName} ${lastName}`);
                greetFullName("Mohammad", "Ayan");

Default parameter:


                const greetGuest = (name = "Guest") => console.log(`Hello ${name}`);
                greetGuest();
                greetGuest("Ayan");

The this Keyword

- Arrow functions do NOT have their own this.
- They inherit this from the parent scope (lexical this).
- Regular functions do have their own this.

Example:


                const obj = {
                    name: "Ayan",
                    role: "JS Developer",
                    show: function() {
                        setTimeout(() => {
                            console.log(this.name); // "Ayan"
                        }, 1000);
                    }
                };
                obj.show();

Key Points to Remember

  • Arrow functions provide shorter syntax
  • Do NOT have their own this
  • Good for callbacks, timers, and functional programming
  • Not suitable as object methods if this is needed
