Local Storage

Local Storage is a web API that allows you to store key-value pairs in the user's browser.

These are the methods provided by Local Storage :

  1. setItem(key, value) - Stores key-value pair
  2. getItem(key) - Get the value by key
  3. removeItem(key) - Remove the key-value pair
  4. clear() - Delete everything
  5. key(index) - Get the key on the given position
  6. length - The number of stored items

We can set & get value like an object

localStorage.one = 1; alert(localStorage.one); delete localStorage.one;

1. Both key & value must be a string.

2. We can use the two JSON methods to store objects in localStorage :

JSON.stringify(obj) - Convert an object to a JSON string
JSON.parse(str) - Convert a string to an object (must be a valid JSON)
