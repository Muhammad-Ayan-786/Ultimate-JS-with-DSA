Post Request

To make a Post Request, we need to use fetch options.

Fetch Options

  • method - HTTP method , e.g. GET, POST, PUT, DELETE
  • body - The request body.
let response = await fetch('/url', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: '{"name": "Ayan", "Language": "JavaScript"}' }); let result = await response.json();
