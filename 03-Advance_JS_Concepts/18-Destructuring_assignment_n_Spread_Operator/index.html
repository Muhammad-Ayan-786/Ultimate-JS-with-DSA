Destructuring assignment & Spread Operator

Destructuring assignment is a feature in JavaScript that allows you to extract values from arrays or objects and assign them to variables.

let [x, y] = [1, 2]; // x will be assigned 1 & y will be assigned 2 let [ , x, ...rest] = [10, 80, 7, 11, 21, 88] // x will be 80 rest will be [7, 11, 21, 88]

Similarly we can destructure objects on the left hand side of the assignment.

const obj = {a:1 , b:2} const {a,b} = obj // a will be 1 & b will be 2

Some more examples can be found on MDN Docs.

Spread Operator

Spread operator is a feature in JavaScript that allows you to expand arrays or objects into individual elements.

let arr1 = [1, 2]; let arr2 = [3, 4]; let arr3 = [...arr1, ...arr2]; // arr3 will be [1, 2, 3, 4] let arr2 = [1, 7, 11]; let obj = { ...arr2 }; // obj will be {0:1, 1:7, 2:11} let nums = [3, 5, 6]; console.log(sum(...nums)); // sum will be 14

Other examples can be found on MDN Docs.
