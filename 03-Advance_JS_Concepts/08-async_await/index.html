Async & Await

There is a special syntax to workk with promises in JavaScript.

A function can be made async by using async keyword like this :

async function num() { // async func always returns a promise even if u return a constant return 5; } num().then((value) => { // .then() can be use on async function console.log(value); })

An async function always returns a promise. Other values are wrapped in a promise automatically.
We can do something like this :

num.then((value) => { console.log(value); })

So, async function ensures that the function returns a promise & wraps non-promises in it.

The await Keyword

There is another keyword called await that works only inside async functions.

let value = await promise;

The await keyword makes JavaScript wait until that promise settles and returns its result

Its just more elegant syntax of getting the promise result than promise.then + its easier to read & write.
